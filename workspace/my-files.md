# My Files

### Create Application

<figure><img src="../.gitbook/assets/Xnip2026-10-26_11-27-49.jpg" alt=""><figcaption></figcaption></figure>

There are three ways to create an application:

1. **Quick Create**: Generates an application with the default name "Untitled" and immediately switches to edit mode
2. **Create from Template**: Choose from system-built-in templates or custom templates
3. **Import File**: Only allows importing previously exported application files

### Operations

<figure><img src="../.gitbook/assets/Xnip2026-10-26_11-30-05.jpg" alt=""><figcaption></figcaption></figure>

1. **Rename**: Double-click the file name to modify the application name
2. **Operation Menu**: Click the operation button to expand the dropdown menu and view available operations
