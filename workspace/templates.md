# Templates

On the templates page, you can create custom templates that are visible only to you.

**Usage flow:**

1. Enter the visual editor, click the "View Configuration Data" button, and copy the generated JSON data
   <figure><img src="../.gitbook/assets/Xnip2026-10-26_14-41-57.jpg" alt=""><figcaption></figcaption></figure>

2. Click the "Create" button and paste the copied JSON data into the "Model" field
   <figure><img src="../.gitbook/assets/Xnip2026-10-26_14-44-58.jpg" alt=""><figcaption></figcaption></figure>

3. Fill in other required fields and save the template

4. On the application list page, select "Create from Template" to view and use your created templates
