# Data Sources

On the data sources page, you can perform CRUD operations on already added data sources. Once added, data sources can be directly selected in the component data source configuration.

<figure><img src="../.gitbook/assets/Xnip2026-10-23_17-31-47.jpg" alt=""><figcaption></figcaption></figure>

Click the "Create" button, select the data source type, fill in the required information, and save.
