# Connect a data source

Select a component, switch to the "Data Configuration" tab, and click "Configure Data Source".

<figure><img src="../.gitbook/assets/Xnip2026-09-18_14-39-43.jpg" alt=""><figcaption></figcaption></figure>

Free users can only set up four types of data sources (random data, static data, API, CSV).
