# Setup interactions

Add a title component to demonstrate displaying data corresponding to a bar chart when clicked.

Select the bar chart component and add a new event in the interaction configuration panel, choosing "When clicking on a bar".

<figure><img src="../.gitbook/assets/Xnip2026-09-18_15-40-57.jpg" alt=""><figcaption></figcaption></figure>

Add a new action and select the title component.

<figure><img src="../.gitbook/assets/Xnip2026-09-18_15-41-38.jpg" alt=""><figcaption></figcaption></figure>

Choose "Render Data" and complete the function body through the title component's data schema.

<figure><img src="../.gitbook/assets/Xnip2026-09-18_15-42-58.jpg" alt=""><figcaption></figcaption></figure>

Click preview to see the interaction effect.
