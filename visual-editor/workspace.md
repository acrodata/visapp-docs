### Canvas

The canvas supports the following component operations:
- Drag to move
- Scale adjustment
- Rotation
- Box-select multiple components

### Ruler

<figure><img src="../.gitbook/assets/Xnip2026-10-21_17-16-18.jpg" alt=""></figure>

Ruler and helper line operations:
- Hold and drag the ruler to create a helper line
- Double-click a helper line to delete it
- Click the small eye icon in the top-left corner to hide all helper lines

### Toolbar

The toolbar provides canvas zoom buttons. Keyboard shortcuts are recommended for improved efficiency.
