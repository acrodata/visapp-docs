# 组件设置

<figure><img src="../../.gitbook/assets/Xnip2026-10-22_14-11-05.jpg" alt="" width="319"><figcaption></figcaption></figure>

选中单个组件后，右侧面板显示组件设置。

1. **基础设置**：包括组件尺寸、位置、旋转角度、透明度及定制化配置项等
2. **数据设置**：配置组件的数据源，支持静态数据、随机数据、API、CSV、数据库等多种数据源类型
3. **交互设置**：配置组件之间的交互关系，包括交互事件和交互动作
4. **组件别名**：可在图层面板双击组件名称进行修改
5. **组件信息**：显示组件版本及唯一 ID
