# Component Panel

<figure><img src="../.gitbook/assets/Xnip2026-10-20_15-18-52.jpg" alt=""><figcaption><p>drag component</p></figcaption></figure>

The component panel provides a rich library of visualization components. Click the left tabs to switch between different component categories.

Two methods are supported for adding components:

* Drag and drop components onto the canvas
* Click a component to automatically add it to the top-left corner of the canvas
